# budget
## Steps
  1. Export CSV files from bank account and format with
     - Column 1 - Date
     - Column 2 - Description
     - Column 3 - Amount
     Note: See 2025-01 folder for CSV file format examples
  2. Configure categories.csv to match your transaction categories
  3. Run categorize_csv_transactions.py to generate log file. Use this log file to evaluate spending habits.
