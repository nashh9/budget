# budget
1. Export CSV files from bank account(s) and format (folder 2025-01 has examples)
   - Column 1 - Date
   - Column 2 - Description
   - Column 3 - Amount
2. Store these files in a folder named YYYY-MM
3. Configure categories.csv to match your transaction categories. Store this file in YYYY-MM folder.
4. Run categorize_csv_transactions.py to generate log file. Use this log file to evaluate spending habits.
